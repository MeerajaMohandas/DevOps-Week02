# DevOps-Week02

Overview

This repository contains basic DevOps learning exercises and reference files covering Linux, Git, Python, and Terraform. It also includes a simple Python calculator demonstrating basic arithmetic operations.

Repository Contents
1. Linux Commands

A collection of commonly used Linux commands for:

File and directory management
Navigation
Permissions
Process management
Basic system operations
2. Git Commands

A reference for frequently used Git commands, including:

Repository initialization
Branch management
Staging and committing changes
Pushing and pulling code
Merging branches
3. Python Modules

A list of commonly used Python modules with basic usage examples to help understand module imports and functionality.

4. Terraform Commands

Basic Terraform commands used for Infrastructure as Code (IaC), including:

Initialization
Validation
Planning
Applying changes
Destroying infrastructure
5. Simple Calculator

A basic Python program that performs two arithmetic operations:

x = a + b
y = a - b

Where:

x stores the sum of two numbers.
y stores the difference between two numbers.
Technologies Used
Linux
Git
Python
Terraform
Purpose

This repository was created as part of DevOps practice to gain hands-on experience with:

Linux command-line operations

Python programming basics
Terraform fundamentals
